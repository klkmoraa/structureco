# Presentación Ruta Conecta

Presentación web independiente creada con HTML, CSS y JavaScript. No requiere instalación ni dependencias.

## Abrir en Visual Studio Code

1. Abre la carpeta `presentacion-autotransporte`.
2. Abre `index.html` en el navegador o usa la extensión **Live Server**.
3. Edita directamente en la portada los nombres, institución y fecha.

## Controles

- Flechas, espacio o botones: cambiar diapositiva.
- `N`: mostrar u ocultar el guion del expositor.
- `F`: entrar o salir de pantalla completa.
- `Inicio` / `Fin`: ir a la primera o última diapositiva.
- Deslizar horizontalmente en pantalla táctil: navegar.

## Exportar a PDF

Usa la opción **Imprimir** del navegador, orientación horizontal, sin márgenes y con gráficos de fondo activados.

La presentación funciona sin internet. La tipografía externa tiene alternativas locales si no hay conexión.
